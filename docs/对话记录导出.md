## 9. NSP 封装结果

### 9.1 采用的实际封装路线

由于 Nro2Nsp 旧版 trampoline 与新版 libnx/NPDM 工具不兼容，最终改为：

1. 使用 `elf2nso` 将 EasyRPG ELF 转为 NSO。
2. 使用旧版 `npdmtool` 生成兼容 NPDM。
3. 使用 Python 生成 UTF-8 NACP。
4. 使用 hacbrewpack 将 NSO、NPDM、NACP、图标、完整游戏 RomFS 封装成 NSP。

该路线仍然满足“单文件自包含 NSP”，且比 Nro2Nsp trampoline 更少依赖旧版启动器。
